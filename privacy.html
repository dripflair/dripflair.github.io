Alfred

Privacy policy

Updated November 15, 2026. Alfred is a personal assistant operated for its owner's private use.

Google data accessed and purpose

After the owner authorizes read-only access, Alfred retrieves calendar lists, upcoming calendar events, task lists, and tasks. Event and task fields include titles, descriptions where provided, dates, status, response status, and available links. Alfred uses this data to select an upcoming deadline or incomplete dated task for its morning brief.

Sharing and AI

The selected item's title, date, and available link are sent through Telegram to the owner's paired private chat. Google processes authorization and API requests; Telegram processes delivered messages under its own terms and privacy policy. The Google integration does not send calendar or task data to Alfred's language model or use it to train AI models. Alfred does not sell Google data or use it for advertising.

Storage and retention

OAuth client credentials and a refresh token are stored in a private configuration file on the owner's server with owner-only file permissions. Access tokens and retrieved calendar/task results are processed in memory rather than saved as a local calendar database. A local delivery-date record helps prevent duplicate morning briefs. Delivered messages remain in Telegram until deleted there; server credential deletion does not delete those messages.

Control, revocation, and deletion

The owner can revoke Alfred's access from Google account connections. To remove the integration from the server, delete Alfred's saved Google authorization file and any retained copies, and stop or disable the morning brief. Previously delivered messages can be deleted separately in Telegram.

Website hosting

This information website does not request Google access, collect form submissions, or include analytics scripts. GitHub Pages hosts the website and may process visitor connection data under GitHub's privacy statement.

Contact

Contact the operator through the operator's GitHub profile for privacy questions. Do not include secrets or private Google data in public messages.

Google API Services

Alfred's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
